# Dataset Preparation using Insurance Dataset

## Activity Details
- **Subject:** Machine Learning
- **Activity:** CIE 2 – Activity 1
- **Course Code:** AD3103
- **Project Title:** Dataset Preparation and Exploratory Data Analysis

## Objective
To inspect an insurance dataset, identify data-quality issues, handle missing values and duplicates, perform Exploratory Data Analysis (EDA), and prepare a clean dataset suitable for machine learning applications.

## Dataset Information
- **Dataset Name:** Insurance Dataset
- **Dataset File:** `insurance.csv`
- **Dataset Source:** https://www.kaggle.com/datasets/mirichoi0218/insurance
- **File Format:** CSV

## Work Completed

### 1. Dataset Loading and Inspection
- Loaded the insurance dataset using Pandas.
- Displayed sample records from the dataset.
- Examined the number of rows, columns and data types.
- Calculated basic statistical information.

### 2. Data Cleaning
- Identified missing values in the dataset.
- Handled missing values using appropriate methods.
- Checked and handled duplicate records.
- Checked data consistency and unusual values.

### 3. Exploratory Data Analysis (EDA)
- Analysed numerical and categorical features.
- Calculated summary statistics.
- Created visualizations to understand the dataset.
- Observed patterns and relationships between different features.

### 4. Data Encoding
- Identified categorical features.
- Converted categorical values into numerical representations using suitable encoding techniques.

### 5. Feature Scaling
- Applied an appropriate scaling technique to numerical features.
- Prepared numerical data for future machine learning applications.

### 6. Prepared Dataset
- Verified the cleaned dataset.
- Checked remaining missing values and duplicates.
- Saved the prepared dataset separately as `Insurance_Prepared.csv`.

## Files Included
- `Activity_1_Dataset_Preparation_Pranav_AD3103.ipynb` – Notebook containing the implementation and outputs.
- `insurance.csv` – Original insurance dataset.
- `Insurance_Prepared.csv` – Cleaned and prepared dataset.

## Conclusion
The insurance dataset was inspected, cleaned and analysed using Python libraries. Missing values and duplicate records were checked, exploratory data analysis was performed, categorical features were encoded and numerical features were scaled where appropriate. The final prepared dataset was saved as a separate CSV file for future machine learning tasks.
